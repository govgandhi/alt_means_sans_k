`main.tex` is the PRE manuscript. `supp.tex` contains the post hoc predictor
comparisons, feature ablations, evaluation details, and native factor-balance
proof and diagnostics (`factor_balance.tex`).
The main text imports its section/table references automatically.
`norm_geometry_supplement.tex` retains the separate supporting calculations
for loss accuracy and balanced norm shape.

Run `make main.pdf` here to build the supplement first and then the manuscript;
`make supp` builds only the supplement. Run `make norm-geometry` for the
supporting calculations. The baseline tables are generated by
`python3 scripts/prospective_baselines.py` from the repository root.
The native-factor table is generated by `python3 scripts/factor_balance.py`
in the pinned, patched runtime; see `analysis/factor_balance.md`.
